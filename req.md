# Leafclutch Technologies Website Requirements

## 1. Project Overview

Develop a modern, premium, professional, fast, responsive corporate website for **Leafclutch Technologies Pvt. Ltd.**

The website should present Leafclutch as a technology company providing software, digital, design, training, and other technology services, while also showcasing its SaaS products.

### Core Requirement

The website must be **CMS/Admin Panel driven**.

After the initial development is completed, routine website content must be manageable by the Leafclutch admin team without requiring developers.

The Admin Panel must provide **CRUD (Create, Read, Update, Delete)** operations for all major dynamic content.

# 23. CRUD Principle

The website must follow this principle:

> **Important business content must not be permanently hard-coded into the frontend.**

Example:

### Add New Service

`Admin Panel -> Services -> Add New -> Publish`

The service should automatically appear on the website.

### Add New Product

`Admin Panel -> Products -> Add New -> Publish`

The product should automatically appear in the Products section.

### Publish Blog

`Admin Panel -> Blogs -> Create -> Publish`

The blog should automatically appear in the blog listing.

The same principle applies to:

- Services
- Products
- Blogs
- Jobs
- Training programs
- Internships
- Portfolio
- FAQs
- Testimonials
- Team members
- Clients
- Certificates
- Other dynamic content

# 33. Most Important Requirement

> **Build the website as a fully manageable CMS-driven platform, not just a static landing page.**

Once development is completed, the Leafclutch team should be able to log into the Admin Panel and manage the website independently.

**Admin → Create/Edit/Delete/Publish → Database → Website automatically updates.**

The developer should only be required for new features, major design changes, integrations, or technical modifications.
